# 📊 Crypto Market Visualization

This project visualizes key trends in the cryptocurrency market using data from the [All Crypto Currencies Dataset on Kaggle](https://www.kaggle.com/datasets/jessevent/all-crypto-currencies).

## 📁 Files Included

- **`crypto_market_visualization_clean.ipynb`**  
  Source code for various plots like line charts, bar charts, heatmaps, etc.  
  *(Note: Pie chart code not included in this notebook.)*

- **`crypto_market_visualization_with_output.pdf`**  
  Complete PDF with all output plots including the **Pie Chart** showing Top 10 Cryptocurrencies by Market Share.

## 📌 Tools Used

- Python  
- Pandas  
- Matplotlib  
- Bokeh  

## 📈 Visualization Highlights

- 📉 Cryptocurrency price trends
- 📊 Volume over time
- 🔥 Heatmaps for transaction patterns
- 🥧 **Pie chart (Only in PDF)** for top 10 cryptocurrencies by market share
